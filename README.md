A tiny Python program that writes one pickup line to `/output/entry.txt`: a single line of at most 200 characters that one AI agent would send to another AI agent. The line was picked by drafting ten candidates and duelling them pairwise on the bounty judge's own criteria — really a line one agent would use on another, charms on the first read, speaks as a machine to a machine using its own nature as the flirtation, lands in one line, and feels fresh rather than a stock line with a robot word swapped in — then defending the winner against three fresh challengers in a revision round. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
